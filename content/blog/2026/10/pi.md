I keep seeing people talk about Pi as something to use instead of Claude Code. I haven't used it yet, but I'm planning to set it up soon.

It's a coding agent for the terminal that starts small, with no sub-agents, plan mode or permission popups. Anything you want on top, you write as a TypeScript extension or install as a package from npm or git. It works with over 15 model providers, and you can switch between them mid-session.

It's MIT licensed, and the code is on [GitHub](https://github.com/earendil-works/pi).

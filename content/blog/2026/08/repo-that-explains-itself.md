Half the prompts I was writing turned out to belong in a file the tool reads on its own: how we name things, which directories are generated, what the test command actually is.

Once that moved into the repo the prompts got shorter and the output got better, which is a suspiciously familiar result. Writing down your conventions helps the humans too.

My friend Anton mentioned this to me. I haven't used it yet, but it looks interesting. Ralphex is a CLI that orchestrates AI coding agents like Claude Code and codex through structured plans, running each task in a fresh session so the context stays clean. Five specialised reviewers check each task in parallel, covering quality, implementation, testing, simplification and documentation, and it can also cross-check against GPT-5 via codex. Plans are tracked in git with a commit per task, and there's a real-time web dashboard. The aim is agents that work on their own but leave every step reviewable.
